# Use Case 1 — Customized Java Application Modernization Workshop
## Bob MODE: Agent
## SKILL: java-appmod-create-sampleapp


## How to use the skill as part of an application modernization workshop series

**Step 1: Perform a Java Modernization Workshop (Presentation and Demo)**
- Topics:
    - Explain why Java is still relevant and what's the challenge with Java 8
    - Explain how the JSphere Suite can address the challenge (IBM Library Support for Open Source, MoRE, Liberty, Quarkus)
    - Explain how AMA and IBM Bob can help to modernize existing applications
- Presentation: https://ibm.box.com/s/1yhub1fcnv76v2bu1nxhiz6la0ykzrtg
- Demo:
    - Demo-Flow: Follow the tutorial at https://github.com/LarsBesselmann/LibertyGettingStarted-2026-AMA-Bob-Lab or https://github.ibm.com/Lars-Besselmann/simplePharmacy-Bob-Repository/blob/main/README.md to get an idea how you can demo AMA and IBM Bob together. 
    - Demo-Environment: Either use your local environment or a TechZone environment that contains AMA and Bob, for example: https://techzone.ibm.com/collection/liberty-getting-started-labs-demos/journey-modernization-tools

    - There is also a Replatforming to Liberty video at: https://ibm.box.com/s/20pt7b8dngfuq7rakcc2ylcn5o0nxuub

- As next step, you could propose a free of charge application assessment. To explain in detail how this works, you could use the following deck: https://ibm.box.com/s/ldmgngqzo6xmun35gc1oo3bc6q3jj2h5

**Step 2: Perform a remote application assessment**
- Topics:
    - Let the customer generate the data collection
    - Analyze the data collection and generate a sample application
- Taks in detail:
    - Tasks to be performed by the customer:
        - Let the customer run the Discovery tool (or the binary scanner or wsadmin) to scan their environment.
        - Let the customer send over the data collection that has been generated by the Discovery Tool.
    - Tasks to be done by you:
        - Use the received data collection to analyze the customer estate via AMA and identify modernization issues.
        - Identify the main migration issues.
        - Use the **java-appmod-create-sampleapp** skill to generate a sample application (application source and binaries) with some of those modernization issues.
        - Use the generated data collection to review the application in AMA.
        - Use the generated source code and migration plan to let IBM Bob resolve the issues.

**Step 3: Workshop to present the assessment result to the customer**
- Topics:
    - Use IBM AMA to provide insight into the customer applications and modernization issues.
    - Use AMA and Bob with the generated sample application to demo the Java Modernization end-to-end flow.
    - Summarize the benefits that IBM EAR and IBM Bob can bring to the table.
    - Discuss next steps.
- Details:
    - Use AMA with the customer data collection to show insight into the customer application
        - the issues that have been identified
        - how much effort is estimated per application and overall
        - the generated deployment artifacts
    - Show in IBM AMA that the generated sample application which has similar issues
    - Show that IBM Bob can modernize the application by applying automated fixes and using agentic AI for the other issues
